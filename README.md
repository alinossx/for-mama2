# Эдит для Мамы ❤️
Сайт сделан под трек Дайте танк(!) — "Маленький".

## Инструкция по сборке:
1. Создай в этом корневом каталоге две папки: `images` и `audio`.
2. В папку `audio` положи трек группы Дайте танк(!) и назови его точно: `daitetank-malenkiy.mp3`.
3. В папку `images` положи 15 детских фотографий. Назови их по порядку: `photo1.jpg`, `photo2.jpg`, ..., `photo15.jpg`.
4. Загрузи всю эту структуру на свой репозиторий в GitHub и включи **GitHub Pages** в настройках (Settings -> Pages -> Deploy from a branch).
5. Отправляй ссылку маме!
